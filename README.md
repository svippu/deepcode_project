# 🐍 DeepCode 2025 Hackathon Project

DeepCode is a Python-powered web application built for the **2025 Hackathon**.  
It leverages Flask, PostgreSQL/MySQL backends, and powerful Python libraries for data handling, web scraping, and smooth deployment.

---

## 🚀 Features
- 🌐 RESTful API built with **Flask 3.1**
- 🗄️ Database support via **SQLAlchemy** with **PostgreSQL** (psycopg2-binary) and **MySQL** (PyMySQL)
- 📊 Data processing & analytics using **pandas 2.2**
- 🔎 Web scraping powered by **requests** & **BeautifulSoup4**
- 🌍 DNS lookups and validations with **dnspython**
- ⚙️ Production-ready deployment using **gunicorn** and **Werkzeug 3.1**
- 📦 Container-friendly, cloud-deployable (Heroku/AWS/GCP-ready)

---

## 🏗️ Tech Stack
| Layer              | Technology Used |
|--------------------|-----------------|
| Backend Framework  | Flask ~ 3.1.0 |
| Database ORM       | Flask-SQLAlchemy / SQLAlchemy ~ 2.0.37 |
| Databases          | PostgreSQL (psycopg2-binary), MySQL (PyMySQL ~ 1.1.1) |
| Data Processing    | pandas ~ 2.2.3 |
| Web Scraping       | requests, beautifulsoup4 |
| Deployment         | gunicorn, Werkzeug ~ 3.1.3 |
| Utility            | dnspython ~ 2.7.0 |
